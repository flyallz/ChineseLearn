# ADR-001：仓库暂时公开

**状态：** 已接受
**日期：** 2026-11-23
**决定人：** 项目负责人（flyallz）

## 背景

- `docs/PRD-V2.2.md` 技术架构表与可维护性一节写的是“GitHub 私有仓库”。
- 实际仓库 `flyallz/ChineseLearn` 是公开的（`private: false`），2026-11-23 核查时 0 星、0 fork、0 个 open issue。
- 仓库里当时只有 5 个文件：`index.html` 原型、README、PRD-V2.2、TD-02 v1.1、CONTRIBUTING v1.1，没有密钥、账号、真实学生数据、后端代码。

## 决定

仓库暂时保持公开，不现在改成私有。

## 理由

- 当前仓库内容没有敏感信息，公开没有泄漏风险。
- 保持公开方便负责人与同学查看、讨论，不用先走邀请流程。
- 改私有随时可以做，不需要改代码，决定可以晚做。

## 护栏（公开期间必须遵守）

- 绝不提交真实密码、密钥、Token、COS 密钥、数据库密码、API Key。
- 绝不提交真实学生数据、真实录音、真实账号信息。
- 测试账号、测试数据与真实账号、真实学生数据分开（见 CONTRIBUTING.md 第 8 节）。
- `.env` 只放本地，模板见 `.env.example`（P0 骨架时补齐）；`.gitignore` 已覆盖 `.env`、`.venv`、`node_modules` 等。

## 放弃了什么

- 放弃了私有仓库的默认隔离：任何人都能看到原型代码、需求文档与技术契约。
- 接受了公开仓库的默认含义：配合根目录 LICENSE（MIT），他人可以在许可证范围内查看与复用代码。

## 复议触发点

出现以下任一情况时，必须重新决定是否改成私有，在此之前不得上线真实账号与真实学生数据：

- V0.2 真实账号开发开始前。
- 任何真实学生数据要进入仓库、测试环境或生产环境之前。
- 仓库里要放任何不适合公开的配置、凭证或内部资料之前。

复议时由负责人决定，决定后更新本文件状态并同步修改 PRD-V2.2 与 CONTRIBUTING 中的相关表述。
