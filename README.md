# 汉语起步 ChineseLearn

留学生学中文网站：从拼音开始，系统学会汉语。

学习路径：拼音 → 日常汉语 → HSK，分级、分过程、分阶梯逐课学；第一课从单韵母 a 开始，四声 ā á ǎ à 可点按试听标准发音。

## 使用方法

本地直接双击打开 `index.html` 即可用，无需安装、无需联网部署（发音音频、插图已内嵌在页面里）。

界面支持 14 种语言切换（中文、English、Tiếng Việt、ไทย、Bahasa Indonesia、မြန်မာ、Français、العربية、한국어、日本語、Русский、Español、Deutsch、Português），切换到非中文语言时可选择“保留中文”显示双语。

## 账号说明

正式开始学习需要注册登录账号。本站为本地演示版：账号与学习进度只存在当前设备的浏览器本地，换设备不同步，清除浏览器数据后无法找回；正式上线需再接后端。
