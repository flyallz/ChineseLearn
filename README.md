# 汉语起步 ChineseLearn

留学生学中文网站：从拼音开始，系统学会汉语。

学习路径：拼音 → 日常汉语 → HSK，分级、分过程、分阶梯逐课学。

课程编号（原型与 PRD 统一）：00 课《什么是汉语拼音》（PRD 第一课）、01 课《认识 a》、02 课《四声与轻声》。首页预览“认识 a”是 01 课的发音体验入口，不是 00 课本身。

## 现有演示行为（`index.html` 原型，当前状态）

- 游客可直接进入学习，无需注册登录。
- 00、01、02 三课已有真实教学内容，其余课程尚未开放。
- 账号与学习进度只存在当前设备的浏览器本地，换设备不同步，清除浏览器数据后无法找回。
- 发音音频、插图已内嵌在页面里，本地双击打开即可用，无需联网部署。

## 计划中的正式产品行为（按 PRD V2.2 路线图）

- 正式开始学习需要注册登录账号，账号与进度由服务端保存，跨设备可恢复（V0.2 起）。
- 第一课按 PRD 定义为《什么是汉语拼音》，8 步，须经 TD-01 审计后迁移（V0.1）。
- 学习事件由服务端记录，教师可查看学习过程并反馈（V0.0 起验证事件闭环）。

## 使用方法

本地直接双击打开 `index.html` 即可用，无需安装、无需联网部署（发音音频、插图已内嵌在页面里）。

界面支持 14 种语言切换（中文、English、Tiếng Việt、ไทย、Bahasa Indonesia、မြန်မာ、Français、العربية、한국어、日本語、Русский、Español、Deutsch、Português），切换到非中文语言时可选择“保留中文”显示双语。
